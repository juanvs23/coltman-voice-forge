Conventions:
- Each task has an ID (`P3-4`), the files it touches, a **check** that decides
  whether it is done, and a size (`S` ≤ 1 h, `M` ≤ half a day).
- Order matters: tasks assume the ones above them exist.
- A task that changes behaviour also updates `docs/context.md` and
  `docs/changelog.md` in the same work unit (AGENTS rule 1–2).
